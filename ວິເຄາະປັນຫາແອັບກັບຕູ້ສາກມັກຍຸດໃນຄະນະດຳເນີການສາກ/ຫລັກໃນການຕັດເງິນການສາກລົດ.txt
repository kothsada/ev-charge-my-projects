 ລະບົບຕັດເງິນ Overstay ເຮັດວຽກແນວນີ້
  
  Timeline ຈາກ session ຈົບ → ຕັດເງິນ

  session ຈົບ (StopTransaction)
         │
         ├─ ຕັດເງິນ: energy + chargingParking + unplug + VAT  ← ທັນທີ
         │
         └─ Redis: set parking:timer:{identity}:{connector}
                {sessionCompletedAt, parkingFeePerMinute: 1000, parkingFreeMinutes: 10}
                           │
                           ▼
                ລູກຄ້າຈອດລົດໄວ້ (ສາຍຍັງສຽບ)
                           │
            ┌──────────────┴──────────────────────────┐
            │ ParkingMonitorService (Cron ທຸກ 1 ນາທີ)  │
            │                                          │
            │  ນາທີ 10: FCM "ຄ່າຈອດເລີ່ມນັບ"           │
            │  ນາທີ 15: FCM reminder + SSE push         │
            │  ນາທີ 20: FCM reminder + SSE push         │
            │  ...ທຸກ 5 ນາທີ...                        │
            └──────────────────────────────────────────┘
                           │
                           │  charger ສົ່ງ: connector → AVAILABLE
                           │  (ລູກຄ້າ ດຶງສາຍອອກ)
                           ▼
                handleConnectorStatusChanged()
                           │
                           ├─ ຄິດ billableMinutes = totalMinutes - 10 (ຟຣີ)
                           ├─ parkingFee = billableMinutes × 1,000
                           ├─ UPDATE wallet SET balance = balance - parkingFee  ← ຕັດເງິນ
                           ├─ create WalletTransaction (type: CHARGE)
                           ├─ FCM push "ຫັກ X LAK"
                           └─ SSE push wallet:updated:{userId}

  3 ຈຸດສຳຄັນ
  
  1. ຕັດຕ່ອນໃດ?

  ▎ ຕັດທັນທີທີ່ charger ສົ່ງ connector → AVAILABLE — ຄື ລູກຄ້າດຶງສາຍອອກ. ບໍ່ຕັດລ່ວງໜ້າ, ບໍ່ຕັດຕາມ timer.

  2. ຖ້າ wallet ຕິດລົບ?

  ▎ ຕັດໝົດ ເຖິງແມ່ນ balance ຕິດລົບ — comment ໃນ code ຈະອະທິບາຍ:
  ▎ "overstay is a penalty the user chose by keeping the car plugged in. Negative balance blocks new sessions until the user tops up."

  3. ຖ້າລູກຄ້າບໍ່ດຶງສາຍເລີຍ?

  ▎ ຕັດບໍ່ໄດ້ — Redis key parking:timer:* expire ຫຼັງ 8 ຊົ່ວໂມງ, ຄ່າຈອດຈະສູນ. ນີ້ຄືຊ່ອງໂຫວ່ທີ່ຍັງມີຢູ່ໃນ system.
